# Physica Documentation

*Physica Documentation* is primarily aimed at developers, intended to clarify the overall architecture, algorithmic design details, and physical considerations of Physica.

Practically, documentation almost always lags behind code updates. Therefore, we attempt to break down the functions of the documentation: **doc** discusses the *Why*, **include** and **src** discuss the *What*, and **examples** discuss the *How*.
